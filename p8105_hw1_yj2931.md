## Create a data frame comprised of:

a random sample of size 10 from a standard Normal distribution a logical
vector indicating whether elements of the sample are greater than 0 a
character vector of length 10 a factor vector of length 10, with 3
different factor “levels”

``` r
set.seed(0)

overwatch_df = tibble(
  sample = rnorm(10),
  positive = sample > 0,
  character = c(
    "mercy", "lucio", "dva", "winston", "doomfist",
    "illari", "jetpack", "kiriko", "wuyang", "ashe"
  ),
  factor = factor(c(
    "support", "support", "tank", "tank", "tank",
    "support", "support", "support", "support", "damage"
  ))
)
```

The mean works only for the numeric and logical variables in this
dataset. For the logical variable, R treats TRUE as 1 and FALSE as 0, so
the mean represents the proportion of TRUE values. The mean does not
work for character or factor variables because they are not numeric.

``` r
as.numeric(pull(overwatch_df, positive))
as.numeric(pull(overwatch_df, character))
as.numeric(pull(overwatch_df, factor))
```

## When using `as.numeric()`…

What happens, and why? Does this help explain what happens when you try
to take the mean?

Logical variables can be converted to numeric values, with `TRUE`
represented as `1` and `FALSE` as `0`, so its mean can be calculated.
Factor variables can also be converted to numeric values based on their
underlying factor levels, but taking mean of factor variables does not
make sense. However, character variables cannot be directly converted to
meaningful numeric values bur NAs.
